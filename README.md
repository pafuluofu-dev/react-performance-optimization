## Overview

Examples of common React performance techniques — lazy loading and memoisation — to avoid unnecessary work and re-renders.

## ✨ Features

- Code-splitting with lazy loading
- Memoisation to skip needless re-renders
- Before/after style examples

## 🛠️ Tech stack

- **React** — memo, useMemo, useCallback, lazy/Suspense
- **Vite** — Per-example tooling

## 🎓 What it demonstrates

- `React.lazy` + `Suspense` for code-splitting
- `memo` / `useMemo` / `useCallback`
- Identifying and removing wasted renders

## 🚀 Getting started

This repo holds several example folders. Open a folder and run:

```bash
npm install
npm run dev
```
